# IULinux: Designing and Building a Linux Distribution

**Architecture, Implementation, and Testing**  
**Irfan Uruchi** · Version **0.3.5** · 22 November 2026

**[Read the book (PDF)](IULinux_Designing_and_Building_a_Linux_Distribution_v0.3.5.pdf)**

This book examines the engineering of the IULinux Alpha: how its image is assembled and installed, how packages reach the running system, how KDE controls interact with system services, and how failures can be traced across those boundaries. It includes the November 2026 ASUS ROG Strix G16 power-management investigation, command examples, system diagrams, and a bibliography.

## Contents

The 70-page edition contains 13 chapters covering IULinux Alpha architecture, boot and systemd, ISO builds and Calamares, file and package provenance, APT and PackageKit, KDE and D-Bus, power management, firmware, system controls, testing, recovery, laboratory procedures, and release preparation.

## Edition and scope

This is **book version 0.3.5**, an early, versioned edition. Its IULinux implementation descriptions draw on the project record dated **23 October 2026**; the ASUS field case is dated **15 November 2026**. The corresponding October Git commit has not been established from the material available for this edition. Proposed implementations and worked examples are identified in the chapters; they are not presented as measured production results.

The full bibliography and in-text citations appear in the PDF.
